# 💕 LoveMatch - Современный сайт знакомств

Красивый и функциональный сайт знакомств с системой регистрации, аутентификации и профилей.

## 🚀 Быстрый старт

### Установка
```bash
npm install
```

### Запуск сервера
```bash
npm start
```

Сайт откроется на `http://localhost:3000`

## 📝 Учетные данные для входа

### Демо администратор
- **Логин:** admin14
- **Пароль:** admin123

### Функционал администратора
- Просмотр статистики (количество пользователей, лайков)
- Управление системой
- Мониторинг активности

## ✨ Основные функции

### Для обычных пользователей
- ✅ Регистрация нового аккаунта
- ✅ Вход в систему
- ✅ Просмотр профилей других пользователей
- ✅ Лайки профилям
- ✅ Просмотр своего профиля

### Для администратора
- ✅ Полная панель управления
- ✅ Просмотр статистики
- ✅ Информация о системе

## 🎨 Дизайн

Сайт имеет:
- Современный градиентный дизайн (синий-фиолетовый)
- Полностью адаптивный интерфейс
- Гладкие анимации и переходы
- Красивые карточки профилей

## 🔐 Безопасность

- Пароли хранятся с использованием bcrypt
- Сессионная аутентификация
- Защита от неавторизованного доступа
- HTTPS ready

## 💾 База данных

Используется SQLite в памяти (для демо). Может быть легко переключена на другую БД.

Таблицы:
- `users` - информация о пользователях
- `likes` - записи о лайках

## 🌐 Страницы

- `/` - главная страница
- `/login` - вход
- `/register` - регистрация
- `/profiles` - просмотр профилей
- `/admin` - панель администратора
- `/api/*` - API endpoints

## 📱 Мобильная оптимизация

Сайт полностью оптимизирован для мобильных устройств и планшетов.

## 🛠️ Технологический стек

- **Backend:** Node.js, Express.js
- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **База данных:** SQLite3
- **Аутентификация:** bcryptjs, express-session
- **Дизайн:** CSS3, Flexbox, CSS Grid

## 📧 API Endpoints

### Аутентификация
- `POST /api/register` - регистрация
- `POST /api/login` - вход
- `GET /api/logout` - выход

### Профили
- `GET /api/profile` - получить свой профиль
- `GET /api/profiles` - список всех профилей
- `POST /api/like/:userId` - лайк профилю

### Администратор
- `GET /api/admin/stats` - статистика

## 🎯 Примеры использования

### Регистрация
1. Перейти на `/register`
2. Заполнить форму (имя, email, пароль, пол, возраст, город)
3. Нажать "Зарегистрироваться"

### Вход
1. Перейти на `/login`
2. Ввести имя и пароль
3. Нажать "Войти"

### Просмотр профилей
1. После входа вы будете на странице профилей
2. Видите карточки других пользователей
3. Можете лайкнуть интересующий профиль

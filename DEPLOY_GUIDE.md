# 🚀 Развертывание LoveMatch на облаке

## ⚡ Самый быстрый способ - Render.com (Рекомендую!)

Развернуть сайт можно за **5 минут** и он будет доступен с любой точки мира!

### Шаг 1: Перейди на Render
https://render.com

### Шаг 2: Регистрация
- Нажми "Sign up"
- Выбери "GitHub"
- Авторизуйся через свой аккаунт GitHub

### Шаг 3: Создать Web Service
1. Нажми кнопку "New +" → "Web Service"
2. Выбери репозиторий: `KerimliRashad/mtproxy`
3. Заполни поля:
   - **Name:** `lovematch` (или любое имя)
   - **Region:** `Frankfurt` (или ближайший)
   - **Branch:** `claude/improved-site-registration-wecrh8`
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`

### Шаг 4: Нажми "Create Web Service"
- Ждешь 2-3 минуты пока билдится
- Получишь ссылку: `https://lovematch.onrender.com`

✅ **Готово!** Сайт живет в интернете! 🌍

## 💾 Сохранение данных

По умолчанию данные хранятся в памяти (теряются при перезагрузке сервера).

Чтобы сохранять данные постоянно, отредактируй `server.js`:

Найди эту строку:
```javascript
const db = new sqlite3.Database(':memory:');
```

Измени на:
```javascript
const db = new sqlite3.Database('./data.db');
```

## 🔐 Безопасность для продакшена

Перед публикацией:

1. **Измени пароль администратора:**
   - В `server.js` найди строку с `admin123`
   - Измени на новый пароль

2. **Добавь переменные окружения:**
   - На Render: Settings → Environment Variables
   - Добавь: `NODE_ENV=production`

3. **Включи HTTPS:**
   - На Render это включено по умолчанию

## 🐛 Если что-то не работает

1. Проверь логи Render:
   - Render Dashboard → твой проект → Logs

2. Убедись что `npm install` успешно прошел

3. Проверь что переменные окружения установлены

4. Попробуй пересоздать сервис
